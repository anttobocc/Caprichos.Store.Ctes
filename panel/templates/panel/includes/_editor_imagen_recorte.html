{% comment %} Editor visual de imagen en modo "recorte" (X/Y % + zoom %), reutilizable para cualquier imagen que se muestre recortada dentro de una caja de aspect-ratio fijo (portada del hero, producto, combo). Ver static/js/panel_categoria_imagen.js para la lógica y panel/includes/_categoria_panel_campos.html para el equivalente en modo "flotante" (imágenes decorativas de categoría/pedidos). Contexto esperado: campo_imagen -> BoundField del ImageField (ej. form.imagen) campo_pos_x -> BoundField de la posición X en % (0-100) campo_pos_y -> BoundField de la posición Y en % (0-100) campo_zoom -> BoundField del zoom en % (100-200) imagen_actual -> el ImageField ya resuelto de la instancia (o vacío si es nuevo) aspecto -> relación de aspecto del recuadro real, ej. "4 / 3" (opcional, default 4/3) etiqueta -> texto del
